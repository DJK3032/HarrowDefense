The node beneath the radio.

PYLON is worn by every soldier, not just the leader. It carries their position and the readings from their wearables onto the network the unit already runs, and goes silent when they need it to.

Request the technical brief

Every soldier on the map

An individual position for each soldier, sent as Cursor on Target so it lands in TAK with no gateway server and no custom integration.

Sensors ride along

PYLON pairs with the Bluetooth wearables already on the soldier and carries their readings with position, processed at the edge so the network carries events, not raw streams.

Quiet on command

Emission control is enforced in hardware, not set in software. A sealed, glove-operable switch takes the node off the air, and nothing remote can turn it back on.

It rides what the unit already carries.

PYLON is not a radio, a soldier computer or a display. It sits underneath them, works alongside fielded radios and end-user devices, and uses open standards on every link. That keeps it small, keeps it affordable enough to issue to everyone, and keeps it out of the way.

The detail is in the brief.

Specifications, architecture, signature data and test results are shared directly with government customers, partners and investors. PYLON is patent pending.
